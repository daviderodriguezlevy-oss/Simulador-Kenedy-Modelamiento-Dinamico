# Simulador territorial de Kennedy

Simulador 3D del proyecto de modelamiento dinámico en Kennedy, Bogotá. Explora el territorio, ajusta las condiciones de partida o compara las alternativas A y B de los seis pares de escenarios.

- [Abrir el simulador en el navegador](https://daviderodriguezlevy-oss.github.io/kennedy-proyecto-territorial/simulador-3d/)
- [Ver el video del proyecto en YouTube](https://www.youtube.com/watch?v=x5zrAuT9yGQ)
- [Consultar la ficha de indicadores](FICHA-INDICADORES.md)
- [Abrir el repositorio del atlas territorial](https://github.com/daviderodriguezlevy-oss/kennedy-proyecto-territorial)

Esta copia reúne el simulador y sus recursos a partir de la versión publicada del atlas. Los resultados exploran las reglas del modelo y no corresponden a pronósticos calibrados.
